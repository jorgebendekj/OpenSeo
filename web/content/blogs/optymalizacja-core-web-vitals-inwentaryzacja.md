Wskaźniki Core Web Vitals są oficjalnym czynnikiem rankingowym Google. Wprowadzenie wskaźnika Interaction to Next Paint (INP) w miejsce FID zwiększyło nacisk na płynność działania interfejsów JavaScript.

## Kluczowe metryki Core Web Vitals:

1. **LCP (Largest Contentful Paint):** Czas załadowania największego elementu graficznego lub tekstowego (cel: < 2.5 s).
2. **INP (Interaction to Next Paint):** Czas reakcji strony na kliknięcia i interakcje użytkownika (cel: < 200 ms).
3. **CLS (Cumulative Layout Shift):** Stabilność wizualna i brak nieoczekiwanych przesunięć elementów (cel: < 0.1).
